# Gilhound

FFXIV market-board flipping assistant for Windows: flip scans, periodic snipe
scan with Discord notifications, and position tracking from plugin data
(CashFlow, AllaganMarket, Allagan Tools, Restocky).

Work in progress — see [docs/PLAN.md](docs/PLAN.md).

Gilhound only reads public market APIs (Universalis, Saddlebag Exchange) and
files that Dalamud plugins write on your PC. It does not interact with the game.
